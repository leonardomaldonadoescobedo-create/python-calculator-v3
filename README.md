# Python Calculator v3

A modular command-line calculator built with Python. Version 3.0 focuses on improving code organization, creating reusable functions, and expanding the calculator with new mathematical operations.

## Features

### Planned Operations

- Addition
- Subtraction
- Multiplication
- Division

### Other Operations 

- Percentage
- Power
- Modulo
- Square Root
- Factorial

## Technologies

- Python
- math module

## What I Practiced in This Version 

- Functions ("def")
- Parameters and arguments
- "return"
- Lists
- "for" loops
- "while True"
- "if", "elif", and "else"
- "try/except"
- Error handling
- Python modules
- Code organization

## Version History

### V1.0
First version of the calculator. Created as an initial learning project but not uploaded to GitHub.

### V2.0
First version published on GitHub with basic mathematical operations and percentage calculation.

### V3.0
Expanded the calculator into a modular command-line application with multiple functions, organized menus, error handling, and mathematical operations.

## About

This project started as a simple calculator and has evolved into Version 3.0. It documents my progress learning Python by gradually improving the structure, functionality, and reliability of the program.
